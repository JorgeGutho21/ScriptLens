## Novedades

Primera versión pública: panel de rendimiento en tiempo real, administrador de procesos con firmas y explicaciones, optimización supervisada, centro de seguridad de solo lectura, analizador de scripts BAT/CMD/PowerShell con MITRE ATT&CK y regresión logística balanceada, asistente local con Ollama y Qwen3 4B Instruct, comparación de diagnósticos, informes PDF/HTML e instalador por usuario.

## Requisitos mínimos

Windows 10 (1809+) u 11 de 64 bits, 4 GB de RAM (8 GB para la IA local), 200 MB de disco (3 GB con el modelo de IA) y WebView2.

## Instrucciones

Consulte [docs/instalacion/INSTALACION.md](../instalacion/INSTALACION.md). Verifique el SHA-256 antes de instalar.

## Problemas conocidos

- El instalador no tiene firma de código comercial: Windows SmartScreen mostrará un aviso.
- El primer arranque puede tardar hasta 30 s mientras el antivirus examina el motor empaquetado.
- La verificación de firmas de todos los procesos tarda alrededor de un minuto tras abrir la sección Procesos.
- El historial de amenazas de Defender puede requerir permisos de administrador; en ese caso se informa como «Información insuficiente».
- La temperatura del hardware no está disponible.
- El clasificador de scripts se entrenó con un corpus sintético; su desempeño en scripts reales debe validarse con más datos etiquetados por dos personas.
