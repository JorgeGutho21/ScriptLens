ScriptLens IA se distribuye bajo licencia MIT. Incluye o utiliza los siguientes componentes, cada uno bajo su propia licencia.

| Componente | Licencia | Uso |
|---|---|---|
| [psutil](https://github.com/giampaolo/psutil) | BSD-3-Clause | Métricas del sistema y respaldo de lectura de procesos |
| [FastAPI](https://github.com/fastapi/fastapi) | MIT | API local |
| [Starlette](https://github.com/encode/starlette) | BSD-3-Clause | Base de FastAPI |
| [Pydantic](https://github.com/pydantic/pydantic) | MIT | Validación de datos |
| [Uvicorn](https://github.com/encode/uvicorn) | BSD-3-Clause | Servidor HTTP local |
| [Tauri](https://github.com/tauri-apps/tauri) | MIT / Apache-2.0 | Contenedor de escritorio e instalador |
| [React](https://github.com/facebook/react) | MIT | Interfaz |
| [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) | MIT | Estilos |
| [Lucide](https://github.com/lucide-icons/lucide) | ISC | Iconos |

Las dependencias transitivas de Rust y npm conservan sus licencias; el listado completo se genera para cada versión publicada.
